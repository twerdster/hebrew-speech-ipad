# Hebrew Speech Recognition on iPad: historical project record

Read this file, then SKILL.md, README.md and PROJECT_RECORD.md.

The historical Hebrew dictation project was developed by Nadav Merlis and Liora Neeman, supervised by Aaron Wetzler. The recovered materials are the description, credits and microphone thumbnail. No original application source, recognizer, report, training data, model, executable or build configuration has been recovered for publication here.

The current repository contains only historical documentation and the archived thumbnail. The later browser demonstration, its code, deployment workflow and implementation records were removed at Aaron’s request on 2026-11-20. There is no software to install, run or deploy from the current tree.

Preserve the student credits, thumbnail provenance and the qualified archival spelling of Koby Kramer. The description does not establish a recognition method, supported vocabulary, training procedure or error rate. The thumbnail creator was not recorded; no blanket license is added.

Maintenance checks cover the historical record, Markdown links, thumbnail integrity and absence of implementation or deployment files. They do not establish recognition accuracy or device compatibility. Keep SUMMARY.md and SKILL.md synchronized before committing.
